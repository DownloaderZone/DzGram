Bound Methods
=============

Bound methods are methods attached to the objects returned by the API (e.g. :meth:`~pyrogram.types.Message.reply`), which allow you to act on them without passing the client explicitly.

They are documented together with their parent type in the :doc:`../types/index` reference.
